02 / DOCUMENTATION

Semua endpoint,
satu pola.

Gunakan code sebagai identifier dan teruskan nilai parent ke endpoint berikutnya.

01 Provinsi /api/v1/provinces.json ↓

Ambil seluruh daftar provinsi dalam dataset publik.

REQUEST
GET ./api/v1/provinces.json
RESPONSE · DIPERSINGKAT
{
  "data": [{
    "id": 1,
    "code": "51",
    "name": "Bali",
    "external_codes": { "rajaongkir": "1" }
  }],
  "meta": { "count": 38, "api_version": "v1" }
}
02 Kabupaten / Kota /api/v1/regencies/{province_code}.json ↓

Masukkan province_code untuk mengambil kabupaten dan kota di dalam provinsi tersebut.

REQUEST
GET ./api/v1/regencies/51.json
RESPONSE · DIPERSINGKAT
{
  "data": [{
    "id": 1,
    "code": "5103",
    "province_code": "51",
    "type": "Kabupaten",
    "name": "Badung"
  }],
  "meta": { "count": 9, "parent_code": "51" }
}
03 Kecamatan /api/v1/districts/{regency_code}.json ↓

Masukkan regency_code untuk mengambil kecamatan pada kabupaten atau kota.

REQUEST
GET ./api/v1/districts/5103.json
RESPONSE · DIPERSINGKAT
{
  "data": [{
    "id": 1,
    "code": "5103010",
    "regency_code": "5103",
    "name": "Abiansemal"
  }],
  "meta": { "count": 6, "parent_code": "5103" }
}
04 Desa / Kelurahan /api/v1/villages/{district_code}.json ↓

Masukkan district_code untuk mengambil desa dan kelurahan.

REQUEST
GET ./api/v1/villages/510303.json
RESPONSE · DIPERSINGKAT
{
  "data": [{
    "id": 1,
    "code": "5103032008",
    "district_code": "510303",
    "name": "Abiansemal"
  }],
  "meta": { "count": 18, "parent_code": "510303" }
}
05 Metadata /api/v1/meta.json ↓

Lihat versi API dan jumlah data pada setiap tingkat wilayah.

REQUEST
GET ./api/v1/meta.json
RESPONSE
{
  "api_version": "v1",
  "counts": {
    "provinces": 38,
    "regencies": 488,
    "districts": 7253,

  }

03 / FAQs

Pertanyaan yang
sering muncul.

Apakah API ini membutuhkan autentikasi?↓

Tidak. Dataset tersedia sebagai file JSON statis sehingga dapat diambil langsung oleh aplikasi Anda.

Bagaimana cara menemukan endpoint turunan?↓

Gunakan nilai code dari response tingkat sebelumnya sebagai parameter endpoint berikutnya. Playground di atas membantu mencoba alurnya.

Format response seperti apa yang dikembalikan?↓

Setiap endpoint mengembalikan object dengan data dan meta. Lihat contoh request dan response pada Docs.

Apakah tersedia dataset flat?↓

Ya. Dataset flat tersedia di /api/v1/data/ untuk kebutuhan importer atau seeder. Daftar path lengkapnya ada di repository.
